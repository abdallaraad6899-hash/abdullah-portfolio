REFERENCE GUIDE

How the algorithm works

A guided overview of the mathematics used in this educational implementation.

01
Build the private sequence

Choose a superincreasing sequence W. Every element is larger than the sum of all earlier elements. This makes subset-sum recovery straightforward using a greedy method.

W = [2, 3, 7, 14, 30, 57, 120, 251]
02
Choose Q and R

Choose Q greater than the sum of W, and choose R such that gcd(R, Q) = 1. This guarantees that R has a modular inverse modulo Q.

Q = 491 · R = 41
03
Derive the public key

Multiply each private sequence element by R and reduce modulo Q. The resulting sequence B is used for encryption.

Bᵢ = (Wᵢ × R) mod Q
04
Encrypt each byte

Convert each UTF-8 byte into eight bits. Multiply each bit by the corresponding public-key element and add the values.

C = Σ (bᵢ × Bᵢ)
05
Reverse the modular step

Calculate R⁻¹ modulo Q, then multiply each ciphertext block by that inverse modulo Q to recover a sum based on W.

S = (C × R⁻¹) mod Q
06
Recover the byte and decode

Use the superincreasing property to recover the eight bits from the largest W value downwards. Join the bytes and decode them as UTF-8.

Recovered bits → bytes → text
Educational note

The original Merkle–Hellman cryptosystem was cryptanalyzed and is not secure for modern real-world communication. This lab is intended for learning and demonstration only.
